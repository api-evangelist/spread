# SPREAD

> SPREAD is a Berlin-based, AI-native engineering intelligence platform for complex product development and manufacturing. It unifies fragmented product lifecycle data across PLM, CAD, ERP, requirements, and simulation systems into a single engineering ontology so teams building automotive, defense, and industrial products can find issues earlier and ship faster. Backed by HV Capital.

This file is generated by the API Evangelist enrichment pipeline from public sources. SPREAD does not publish a public developer API surface; the platform is delivered as enterprise solutions and a low-code studio.

## Products
- Engineering Platform: central intelligence layer connecting engineering tools and data
- Requirements Manager: AI-assisted requirements validation and conflict detection
- Product Explorer: natural-language querying across product architecture
- Error Inspector: root-cause analysis tracing field issues to components and requirements
- Action Tower: engineering action and workflow surface
- SPREAD Studio: low-code environment for custom applications and analyses
